# Sample run, 2026-10-07: 52 questions

## Setup

- **Model:** `claude-sonnet-5` via the Claude Agent SDK, effort `medium` (the client default).
- **Questions:** 52 in total.
  - 50 derived questions, stratified by source checklist with proportional allocation,
    seed `20261007`: chemistry 14 (pool 78), equipment 11 (pool 65), microbiology 9 (pool 53),
    Part 130 requirement 11 (pool 60), sampling 5 (pool 29).
  - The 2 authored questions in `eval/authored.json`.
- **Attempts:** up to 3 per question. A rejected draft is re-prompted with the reason for each
  failed quotation.
- **Concurrency:** 3.
- **Commands:** `npx tsx eval/run-sample.mts`, then `python3 eval/analyze.py`.

## Results

| Measure | Result |
|---|---|
| Answered | 44 / 52 |
| Withheld after 3 attempts | 3 / 52 |
| Errors | 5 / 52 |
| Displayed quotations verified | All of them. The gate checks every quotation before display. |
| Drafts with at least one unverifiable quotation | 35 / 85 (41%) |
| Questions that needed at least one retry | 24 / 52 (46%) |
| Correct source document, answered questions with an expected document | 34 / 36 (94.4%) |
| Latency, median / p90 | 18.8 s / 61 s |

The gate rejected all 35 drafts for the same reason, `quote-not-found`: 32 rejections led to a
retry and 3 ended a question as withheld. No rejection was for a table-of-contents quotation or
an unknown document.

The harness's own summary reports `quoteVerified` and `anchorResolves` as 44/52 (84.6%). That
is because it scores every unanswered question as a failure on those axes. No unverified
quotation was displayed.

The authored silence question (`audit-trail-retention`) was answered correctly as silent.
Of the 43 answered questions that were not about silence, 4 (9.3%) declared silence anyway.

Two answered questions cited the wrong document. Both expected the LQSS. One cited
the microbiology checklist and declared silence. The other cited Part 130 §§ 130.26–130.27.

## Known issues

1. **Tool calls despite `allowedTools: []`** (3 errors). The model sometimes tries to use a
   tool. The SDK then ends with `error_max_turns` because `maxTurns` is 1.
2. **Invalid JSON is not retried** (2 errors). In one case the model returned prose instead of
   JSON. In the other, its JSON did not parse. The pipeline treats both as errors and does not
   re-prompt.
3. **Quotations from tables fail the gate** (3 withheld). The model copied text from inside a
   table cell. In the `pdftotext -layout` output, neighbouring columns appear between the lines
   of that cell, so the quotation does not occur in the text as one run.
4. **The authored set has only 2 questions.** The spec calls for 20–30. Inference and silence
   behaviour are therefore barely measured. These results mostly measure lookup.

## Limitations

- This is one run of 52 questions, and the derived questions only test lookup. The numbers
  are indicative and have wide uncertainty.
- The "correct source document" check only looks at the document. It does not check whether
  the answer is right in substance. Nobody scored the answers by hand in this run.
